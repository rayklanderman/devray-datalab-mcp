# Roadmap

DevRay DataLab MCP follows [semantic versioning](https://semver.org/). The current release is `v0.1.0`.

The items below are proposals for future versions. They are **not implemented** and will be prioritized based on community feedback.

## v0.2.0 (proposed)

- Additional classification and regression algorithms (SVM, k-NN, gradient boosting)
- Automated model comparison and hyperparameter tuning
- Feature importance and feature selection
- Improved experiment tracking
- Training progress and cancellation via MCP progress mechanisms
- Better CPU and memory resource controls
- Optional GPU acceleration through separate, opt-in dependencies
- Excel and Parquet dataset support
- Improved error reporting and model reproducibility

## Longer-term

- Dataset profiling and automated preprocessing recommendations
- Optional GPU-accelerated backend plug-in (without redesigning MCP tools)
- Batch prediction workflows

## Versioning

Releases are published to PyPI as `devray-datalab-mcp` and registered in the MCP Registry as `io.github.rayklanderman/devray-datalab-mcp`. Release notes accompany each GitHub release.

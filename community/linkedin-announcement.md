# LinkedIn Announcement

Excited to share the launch of **DevRay DataLab MCP** (v0.1.0), an open-source, local-first
Model Context Protocol (MCP) server for data science and machine learning — now available on
PyPI and registered in the official MCP Registry.

DevRay DataLab MCP lets AI coding assistants (Claude, Cursor, Cline, Kilo Code, and OpenAI
Codex) perform real dataset analysis, preprocessing, and machine learning model training entirely
on your own computer — using your own CPU and RAM. No cloud hosting, no API keys, no paid
subscriptions. Your datasets never leave your machine.

Ten MCP tools cover the full workflow: inspect datasets, data-quality reporting, correlation
analysis, preprocessing (fit on training data only — no leakage), classification/regression
training, model comparison, model export, prediction, and hardware info.

Install in seconds:

```powershell
pip install devray-datalab-mcp
```

or with uvx:

```powershell
uvx devray-datalab-mcp
```

Registered as `io.github.rayklanderman/devray-datalab-mcp` in the official MCP Registry
(transport: stdio).
